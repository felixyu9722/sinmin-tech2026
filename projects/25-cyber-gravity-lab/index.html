人机协作创作脉络展示

演示中学生如何通过精准 Prompt 指令一步步构建该复杂物理引擎网页。

STEP 1: 架构搭建 (Initial Prompt)
"请作为资深前端专家，用单文件 HTML/CSS/JS 编写一个【交互式重力粒子画布】。 实现核心功能：使用 Canvas 渲染粒子，鼠标靠近时粒子聚集，点击时爆开，并提供粒子数量与重力的控制面板。"

💡 成果：生成了基础的物理画布和原生 HTML 滑块控制逻辑。

STEP 2: 视觉提升 (Style Enhancement)
"请将整体风格重构成『暗黑赛博朋克风格』。 加入 Tailwind CSS、网格阴影、CSS 霓虹发光（Neon Glow）以及玻璃拟态（Glassmorphism）浮动面板。 粒子增加能量连线，并提供 4 套赛博霓虹主题色（赛博霓虹、翡翠光极、深海冰蓝、烈焰红莲）一键切换。"

💡 成果：界面大幅跃升为科幻展会级视觉效果，粒子间连线增加科技感。

STEP 3: 玩法深化与音效 (Game & Web Audio)
"在物理画布的基础上，拓展一个『迷你赛博防御游戏模式』。 利用 Web Audio API 合成激光和爆炸音效（不依赖外部音效文件）。 增加下落的赛博病毒，允许玩家拖拽光标护盾进行拦截，计算连击与积分，并在核心被破毁时弹出高分结算弹窗。"

💡 成果：成功将静态展示转化为具备强烈互动感的展会互动游戏。

学生现场讲解提纲：

AI 不是代码的替代者，而是创意加速器。我们通过『递进式提示词工程（Iterative Prompting）』，将复杂的数学物理演算与 Web 音频接口分层落地，最终完成此项科技展作品。
