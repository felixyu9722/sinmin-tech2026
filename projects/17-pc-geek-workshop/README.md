# PC 极客工坊：电脑硬件与网络探秘交互式教学实验平台 (PC Hardware & Network Craft)

> **独中高中资讯科技（高一/高二）• 计算机硬件系统体系结构、组装实务与网络拓扑交互式教学软件**

---

## 📖 项目简介

本项目为专为马来西亚华文独立中学（独中）高中资讯科技科学生与教师打造的高品质互动网页游戏与教学实验平台。
平台采用**纯原生 Web 前端技术栈（HTML5 + Vanilla CSS + ES6+ JavaScript + Web Audio API）**构建，**零外部环境依赖、零网络跨域问题、双击 `index.html` 即可离线完美运行**。

系统全面摒弃了幼稚低幼的 Emoji 占位，全量采用**专业级 2.5D 矢量硬件插画（Clipart）与高清实物器件图**，深度对齐董总《高中资讯科技》最新统考课纲标准。

## 🎮 四大核心互动学习模式

### 1. 🛠️ 虚拟装机与排错实验室 (2.5D PC Assembly & Diagnostics Workbench)
*   **高精细度 2.5D ATX 主板**：集成 LGA 1700 触点插座、DDR5 内存双通道槽、M.2 PCIe 4.0 固态槽、金属加固 PCIe x16 显卡槽与 14 相数字供电模组。
*   **防呆对齐与规范化 7 步装配指引**：
    1.  **CPU 安装**：金色防呆三角对齐插槽防呆标，双侧定位缺口保护针脚。
    2.  **导热硅脂 (TIM)**：填补微观空气缝隙，学习热传导物理原理（热阻与导热率）。
    3.  **散热器与风扇**：六热管双塔风冷安装，并接驳 `CPU_FAN` 4-Pin PWM 温控插头。
    4.  **DDR5 双通道内存**：优先插在第 2 槽 (A2) 与第 4 槽 (B2)，解析菊花链拓扑信号完整性。
    5.  **M.2 NVMe SSD**：高亮提示撕除主板散热马甲内侧出厂蓝色导热垫保护膜。
    6.  **独立显卡 (RTX 4070)**：插紧 PCIe 4.0 x16 插槽，强调显示器视频线必须直连独显接口。
    7.  **电源线组**：接通 24-Pin 主板供电与 8-Pin CPU 辅助供电。
*   **开机通电自检 (POST) 与 UEFI BIOS 大屏**：
    *   主板 Debug 诊断灯依次自检（CPU 红 $\rightarrow$ DRAM 黄 $\rightarrow$ VGA 白 $\rightarrow$ BOOT 绿）。
    *   风扇真实旋转动画与电机运转声音。
    *   通电成功清脆单声蜂鸣（Beep），弹出完整硬件检测参数大屏。
*   **实战故障排除演练 (DRAM 报警)**：
    *   一键切换实战排错模式，模拟开机黑屏、主板 DRAM 黄灯常亮与连续报警长鸣，学生通过点击松动内存条完成实战排解。

### 2. 🔬 微观透视与存储天梯 (Hardware X-Ray & Instruction Cycle)
*   **CPU 体系结构剖析与指令执行周期 (Machine Cycle)**：
    *   运算器 (ALU)、控制器 (CU)、寄存器组 (PC、IR、ACC、R1、R2) 与三级缓存 (L1/L2/L3)。
    *   **动态激光导轨粒子流向演练**：
        1. **取指 (Fetch)**：从外部主存储器 RAM 垂直注入指令寄存器 IR，PC 自动递增。
        2. **译码 (Decode)**：从 IR 暂存器向上送入控制单元 CU 译码器，发出微指令脉冲。
        3. **执行 (Execute)**：操作数从 R1、R2 沿内部数据总线进入算术逻辑单元 ALU 计算。
        4. **写回 (Store)**：计算结果从右上角 ALU 累加器 ACC 沿专用写回总线精准存回左下角 R1 寄存器。
    *   支持自动连续演示、单步步进、暂停、速度切换（慢速 3.8s / 常规 2.0s）及步进器药丸跳转。
*   **存储层次速度大对决 (Storage Hierarchy Speed Race)**：
    *   CPU 快取 (Cache ~1,200 GB/s) vs 主内存 (DDR5 96 GB/s) vs M.2 NVMe SSD (7,400 MB/s) vs 普通 SATA SSD (550 MB/s) vs 机械硬盘 (150 MB/s)。
    *   一键启动 1GB 数据读取实测竞速赛，并深度剖析虚拟内存 (Virtual Memory) 与颠簸机制。
*   **高速缓冲存储器 (Cache) 动态光晕与极速命中演练 (Cache Hit Simulator)**：
    *   集成微光扫描线、高频雷达脉冲徽章（命中率 95%+）、SRAM 1ns 极速命中交互按钮。
    *   生动演示**程序局部性原理 (Locality of Reference)**：CPU 核心优先扫描 L1/L2/L3 快取，无需等待慢速 RAM (15ns)，彻底打破存储速度墙；在取指 (Fetch) 阶段全自动同步光晕联动。
*   **CPU vs GPU 并行对决 (Parallelism Arena)**：
    *   “8 位数学教授（低延迟串行）” 对比 “5000+ 流水线工人（高吞吐并行）”，4K 像素并行渲染实测。

### 3. 🌐 网络拓扑与数据流动可视化 (Network Topology & Data Flow)
*   **家庭式网络 (Home SOHO)**：
    *   从电信 ISP 光纤入户 $\rightarrow$ 调制解调器/数据机 (Modem) $\rightarrow$ 无线路由器 $\rightarrow$ 电脑 / 手机 / 智能电视。
    *   支持【⬇️ 下行接收】与【⬆️ 上行发送】动态慢速（2.0s）粒子流向推演，界面干净整洁直观。
*   **学校校园局域网 (School Campus & Dual APs)**：
    *   ISP 校园光纤专线 $\rightarrow$ Modem $\rightarrow$ 核心路由器/防火墙 $\rightarrow$ 核心交换机 (Switch Hub)。
    *   **下挂 4 大分支清晰呈现**：电脑室 (40台有线 LAN)、教学楼 AP 1 (PoE 供电网线下挂学生平板)、大礼堂 AP 2 (PoE 供电网线下挂教师手机/访客)、**校园服务器 (红色高防核心界面，千兆专线直连)**。
    *   支持【⬇️ 校园下行入校】、【⬆️ 终端上行互联网】以及【🏢 校内内网互访（不走外网光纤）】三向动态时序演示。

### 4. 📝 课纲与小白电脑常识小测验 (Syllabus & Practical PC Quiz)
*   **题库全量扩充至 20 道精选试题（满分 100 分）**：
    *   **计算机体系结构核心（10 题）**：冯·诺依曼架构、易失性 vs 非易失性存储、缓存局部性原理、总线要素、双通道、80 PLUS 金牌能效、硅脂微观导热、显存 VRAM 等。
    *   **小白装机避坑与日常排错（5 题）**：显示线直插独显接口避坑、M.2 导热垫撕出厂防尘薄膜、CPU 金色三角形与定位缺口防呆、主板 Debug DRAM 黄灯故障排查、三年老电脑硅脂老化积灰断电热保护 (PROCHOT)。
    *   **网络实用常识与现代技术（5 题）**：光猫 Modem 光电双向调制解调、双频 Wi-Fi 2.4G vs 5G 穿墙特性对比、核心交换机 Switch 基于 MAC 地址高速转发、Cat 5e/Cat 6 千兆网线规格识别、吸顶 AP 与摄像头 PoE 以太网供电技术。
*   即时正误反馈、独中名师深度考点精析、考后自动评级（极佳/良好/需复习）与成绩单评估。

## 🚀 使用与教学指南

1. **直接运行**：
   * 进入文件夹 `互动教育性游戏`，直接双击打开 `index.html` 即可在任意现代浏览器（Chrome、Edge、Firefox、Safari）中全屏运行，零依赖、零后端。
2. **课堂教学建议**：
   * **硬件组装课**：教师通过投影仪演示【虚拟装机实验室】，让学生上台交互操作装配部件与观察自检 Debug 灯。
   * **计算机原理课**：在讲授冯·诺依曼计算机结构时，切换至【微观透视与存储天梯】运行 FDE 指令周期 4 阶段动态激光导轨与存储速度天梯。
   * **网络基础课**：在讲解调制解调器原理与局域网时，切换至【网络拓扑与数据流动】，推演光电信号调制解调与校园双 AP 交换机内网互访。
   * **复习检测课**：布置【课纲考点小测验】供学生自主通关巩固。
